# Portfolio Rahmi Putri

Website portfolio statis yang dibuat dengan HTML, CSS, dan JavaScript murni. Tidak membutuhkan Laravel, PHP, database, atau proses build sehingga siap dipublikasikan melalui GitHub Pages.

## Menjalankan secara lokal

Buka `index.html` di browser, atau jalankan static server dari folder ini:

```bash
npx serve .
```

## Publikasi ke GitHub Pages

1. Buat repository GitHub baru.
2. Upload seluruh isi folder ini ke repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu simpan.

Form kontak menggunakan `mailto:` karena GitHub Pages tidak menjalankan backend. Jika membutuhkan penyimpanan pesan, gunakan layanan form eksternal seperti Formspree.
